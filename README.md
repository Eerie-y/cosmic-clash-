# 🌌 Cosmic Clash

A cosmic-themed Tic Tac Toe game where strategy meets space!

## 🎮 About the Game

**Cosmic Clash** is a browser-based Tic Tac Toe game with a unique cosmic-inspired design. Challenge your opponent, make your moves, and try to win by getting three marks in a row.

## ✨ Features

- 🌌 Cosmic-themed visual design
- 🎮 Interactive Tic Tac Toe gameplay
- ⚔️ Two-player game experience
- 🖥️ Play directly in your web browser
- 📱 Responsive design, where supported

## 🛠️ Built With

- HTML
- CSS
- JavaScript

## 🚀 Play Online

**Live Demo:** https://eerie-y.github.io/cosmic-clash-/

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Eerie-y/cosmic-clash-.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.
